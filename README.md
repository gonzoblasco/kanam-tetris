# kanam-tetris

Tetris clásico en un solo archivo HTML (sin build, sin dependencias). Proyecto-experimento del pipeline de agentes: v0.1 minimalista escrita por agentes (Claude Code via gateway Ollama), iteraciones futuras la hacen crecer.

## Jugárlo

Abrir `index.html` en el browser. Listo.

| Tecla | Acción |
|---|---|
| ← → | mover pieza |
| ↑ | rotar |
| ↓ | caída suave |
| Espacio | hard drop |

## Estado

- v0.1 (minimal jugable): tablero 10x20, 7 tetrominós, rotación, ghost piece, hard drop, líneas + puntaje + niveles, next piece, game over/reinicio.
- Roadmap vivo en `.knowledge/BRIEF.md` (hold piece, T-spins, sonido, etc. quedan para próximas iteraciones).
